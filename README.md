# trip_platform
🌌 架空世界バーチャル観光プラットフォーム
このプラットフォームは、GoogleドライブとGoogleスプレッドシートをデータベースとして利用する、サーバー構築不要のWebアプリです。ファイルをアップロードし、スプレッドシートを更新するだけで、美しい観光地ガイドが自動的に生成されます。

🚀 セットアップガイド
1. Google Cloud プロジェクトの準備
Google Cloud Console にアクセスし、新しいプロジェクトを作成します。

以下のAPIを有効にします。

Google Sheets API

Google Drive API

「サービスアカウント」を作成し、JSON形式のキーをダウンロードします。

2. Streamlit Secrets の設定
ローカル環境またはStreamlit Cloudで以下のキーを設定してください。


[google_drive]
credentials = '{"type": "service_account", ...}' # ダウンロードしたJSONの内容を貼り付け
3. スプレッドシートの作成
新規スプレッドシート（例: 観光地管理シート）を作成します。

1行目に以下のヘッダーを記述してください。
ユーザー名, 観光地名, 全体説明, 全体画像URL, スポット1説明, スポット1画像URL, スポット2説明, スポット2画像URL, スポット3説明, スポット3画像URL

サービスアカウントのメールアドレスに対し、スプレッドシートの「編集権限」を付与してください。

💡 アプリの使い方
新しい観光地を登録する
アプリ左側のサイドバー 「🚀 新しい観光地の登録」 を展開します。

観光地名や説明文を入力します。

Googleドライブの画像リンクを入力します。

※画像は必ず「リンクを知っている全員が閲覧可能」に設定してください。

「登録」ボタンを押せば、データベース（スプレッドシート）に即座に反映されます。

観光地を閲覧する
メイン画面の「観光地リストを更新」ボタンを押します。

スプレッドシートからデータが取得され、カード型のカラフルなUIで一覧が表示されます。

気になる観光地を「クリック」すると、折りたたまれていた詳細情報や、こだわりの人気スポットTOP3が展開されます。

🛠 開発者向け：画像表示のヒント
Googleドライブの共有リンクをそのまま貼っても表示されません。当アプリでは、ドライブの共有リンクから自動的に画像表示用の直接URLへ変換するロジックを実装しています。

対応形式: [drive.google.com/file/d/](https://drive.google.com/file/d/) から始まるリンク

権限: スプレッドシートとドライブの共有権限を確認してください。
